# Galaxy Gallery — Next.js + PWA + Android

A Samsung One UI-inspired gallery app starter for web and Android. This is an independent project, not affiliated with Samsung.

## Stack
- Next.js App Router, React, TypeScript
- Responsive Samsung One UI-inspired UI
- IndexedDB local photo storage (photos persist across page refreshes in the same browser/app data)
- Optional Supabase Auth + private Storage bucket for cloud backup
- PWA manifest and service worker shell cache
- Capacitor Android wrapper

## 1. Run the web app
Requires Node.js 20+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. Without Supabase credentials, local gallery features still work.

## 2. Configure cloud backup
1. Create a project at https://supabase.com/.
2. Copy Project URL and anon/publishable key into `.env.local` (never use the service-role key).
3. In Supabase Storage, create a **private** bucket named `gallery-photos`, or run `supabase/schema.sql` in SQL Editor (it creates the bucket and policies).
4. Enable Email auth in Authentication > Providers. Adjust email confirmation settings to your preference.
5. Restart the dev server after changing `.env.local`.

Uploads are saved locally first. When signed in, newly added images are also uploaded to the private bucket. Open Settings > Back up existing photos to upload local images that are not backed up yet.

**Current cloud scope:** image objects are uploaded to Storage. This starter keeps gallery metadata (title, favorite, album) in IndexedDB only. It does not yet implement cross-device metadata sync or automatic downloading/restoration of cloud objects on a fresh device. Add a database table and sync workflow before treating it as a full Google Photos/Samsung Cloud replacement.

## 3. Android app using Capacitor
Use Android Studio and Android SDK. On Windows PowerShell, run:

```powershell
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

In Android Studio, wait for Gradle sync, select an emulator or device, then Run. The `android/` directory is generated by Capacitor and is intentionally not included in source control.

After web changes:
```powershell
npm run build
npx cap sync android
```

Set `appId` in `capacitor.config.ts` to your own reverse-domain package ID before publishing. Configure signing in Android Studio for release builds.

## 4. Install as a web app
Deploy the static export (`out/`) to a static host or use Vercel. Serve over HTTPS for PWA installation and service-worker support. On supported browsers, use the browser's Install app / Add to Home Screen action.

## Notes / production checklist
- Browser local storage is device/browser-specific and can be cleared by the user.
- The current service worker caches the app shell, not remote photo files.
- The UI uses a file picker; it does not silently scan a phone's private photo library.
- For large libraries, add thumbnail generation, pagination, EXIF metadata handling, upload progress/retry, storage quotas, and a database-backed metadata sync.
- Review Supabase Auth redirect URLs and Storage policies before production.
